# Ziptrrip Todo Application

## Project Description

This is a simple full-stack Todo Application built using React for the frontend and Node.js with Express.js for the backend. It allows users to add, delete, and view todo items.

---

## Features

- Add Todo
- Delete Todo
- View Todo List
- View Todo Details
- Multiple Pages using React Router
- RESTful CRUD APIs
- JSON File Storage

---

## Technologies Used

### Frontend
- React
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js

---

## Backend Setup

```bash
cd backend
npm install
npm start
```

---

## Frontend Setup

```bash
cd frontend
npm install

```
